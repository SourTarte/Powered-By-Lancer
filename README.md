A theme for the Obsidian Markdown editor based heavily off of the aesthetics of the [Lancer TTRPG](https://massif-press.itch.io/corebook-pdf), and Santi Younger's [Wasp theme](https://github.com/santiyounger/Wasp-Obsidian-Theme).

![](https://i.redd.it/fm4i0pongs0f1.png)
## Installation
- Powered By Lancer _is available in Obsidian Community Themes._
- In Obsidian go to Settings > Appearance > Community Themes > Browse
- Search for: Powered By Lancer
- Click “Use”
- If given any options at this point, select "Overwrite"
- Done!
